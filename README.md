# Broken Apps

Proof cases for [Hound](https://cyberhound.ai). Deliberately
vulnerable apps. Hound tested each one end-to-end on its own.

Writeups live on [cyberhound.ai](https://cyberhound.ai).

## Apps

- [dossier](dossier/). Multi-tenant B2B project workspace.
  Cross-tenant account takeover chained into admin-only report access.

## Run Safely

These apps are deliberately vulnerable. Run them locally. Do not
expose them to the public internet. Do not reuse their seed
passwords anywhere real.
